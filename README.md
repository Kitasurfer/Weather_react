# Weather App with Redux

## English

This is a weather application built using React and Redux. It allows users to:

- View current weather conditions for a specific city
- Search for weather information by city name
- Save weather history cards for previously searched cities
- Delete individual weather cards or clear the entire history

The app features a clean and responsive user interface, with components built using modern React practices. State management is handled by Redux, ensuring predictable data flow and easy debugging.

This program is designed to provide users with a simple and intuitive way to access current and historical weather data. The application's responsive design ensures a seamless user experience across various devices, while the integration of Redux enables efficient state management and scalability.

### Key Features:
- **Real-time weather data**: Fetch up-to-date weather information using a weather API.
- **History tracking**: Save and manage weather search history.
- **Responsive design**: Optimized for both desktop and mobile devices.
- **Redux integration**: Centralized state management for better scalability.

### Technologies Used:
- React
- Redux Toolkit
- TypeScript
- Emotion (for styling)

## Русский

Это приложение для просмотра погоды, разработанное с использованием React и Redux. Оно позволяет пользователям:

- Просматривать текущие погодные условия для конкретного города
- Искать информацию о погоде по названию города
- Сохранять карточки с историей погоды для ранее найденных городов
- Удалять отдельные карточки или очищать всю историю

Приложение имеет чистый и адаптивный пользовательский интерфейс, с компонентами, созданными с использованием современных практик React. Управление состоянием осуществляется с помощью Redux, что обеспечивает предсказуемый поток данных и упрощает отладку.

Эта программа предназначена для предоставления пользователям простого и интуитивно понятного доступа к текущим и историческим данным о погоде. Адаптивный дизайн приложения обеспечивает бесшовный пользовательский опыт на различных устройствах, а интеграция Redux обеспечивает эффективное управление состоянием и масштабируемость.

### Основные возможности:
- **Данные о погоде в реальном времени**: Получение актуальной информации о погоде с использованием API.
- **История поиска**: Сохранение и управление историей поиска погоды.
- **Адаптивный дизайн**: Оптимизация для настольных и мобильных устройств.
- **Интеграция Redux**: Централизованное управление состоянием для лучшей масштабируемости.

### Используемые технологии:
- React
- Redux Toolkit
- TypeScript
- Emotion (для стилизации)
